WEB APPLICATION

Academic Planner

A browser-based planner for university students. It allows the user to add courses, create assignments with a due date and priority, mark tasks complete, filter tasks by state, and delete tasks. Data is saved in localStorage so the list is preserved between visits on the same browser.

HTMLCSSJavaScriptlocalStorage

My role: Designed the interface, modelled the state, and implemented the add / complete / delete cycle.

JAVASCRIPT FORM PROJECT

Contact Form with Validation

A contact form that uses JavaScript to check for empty fields, validate email format with a regular expression, and ensure the phone number contains digits only. Accessible error messages are shown inline, and the form prepares a draft email in the visitor’s email application.

FormsJavaScript validationAccessibility

My role: Built the form, wrote the validation logic, and added accessible error messages.
